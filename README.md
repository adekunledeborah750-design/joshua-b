# Forge Construction Company

> **BUILT ON QUALITY. DRIVEN BY STRENGTH.**

A premium, modern construction company and building materials e-commerce web platform faithfully recreated and adapted from the luxury editorial visual style, typography hierarchy, and motion experience of [Forge Automotive](https://forgeautomotive.co.uk/).

---

## 🌟 Overview

The platform transforms bespoke automotive atelier aesthetics into an architectural construction materials supplier serving building contractors, developers, civil engineers, and homeowners.

- **Brand:** Forge Construction Company
- **Positioning:** Heavy structural supplies, commercial concrete & steel, architectural masonry, and timber supply.
- **Visual Palette:** Deep obsidian black (`#0C0C0C`), architectural charcoal (`#161616`), warm off-white (`#F2F1ED`), and restrained construction bronze accents (`#C5A064`, `#E06D28`).

---

## 🚀 Key Features

### 1. Architectural Header & Navigation
- Sticky blur navigation with scroll detection and scroll progress bar.
- Animated full-screen navigation overlay with numbered editorial indices (`01` through `08`).
- Live cart item counter badge and instant quotation trigger.

### 2. Cinematic Hero Section
- Visual entrance with smooth scale reveals.
- Core brand messaging: *"BUILDING BETTER. BUILDING WITH CONFIDENCE."*
- Direct action triggers for material exploration and custom project quotes.

### 3. Synchronized Storytelling Lifecycle ("EVERY STAGE MATTERS")
- **01 — FOUNDATION:** Substructures, BS EN 197-1 cement mixes, 7.3N concrete blocks, MOT Type 1 aggregates.
- **02 — STRUCTURE:** Kiln-dried C24 framing timber, CARES certified B500B rebar, engineering bricks, heavy-duty lintels.
- **03 — FINISHING:** Low-thermal PIR insulation boards, SoundBloc acoustic linings, natural roofing slate, and architectural screeds.

### 4. 10 Comprehensive Material Categories
1. **Cement & Concrete**
2. **Bricks & Blocks**
3. **Timber & Wood**
4. **Steel & Reinforcement**
5. **Roofing Materials**
6. **Insulation & Plasterboard**
7. **Flooring & Finishes**
8. **Tools & Accessories**
9. **Plumbing Supplies**
10. **Electrical Building Supplies**

### 5. Architectural Projects Gallery ("MATERIALS BEHIND GREAT PROJECTS")
- Landmark residential, commercial, industrial, and heritage restoration profiles.
- Interactive project detail modal displaying metrics, locations, and specified material packages.

### 6. Fully Functional Digital Storefront & E-Commerce
- Real-time catalog search and category filtering.
- Multi-criteria sorting (popularity, price, alphabetical).
- Unit and pack size specifications with live stock status indicators.
- Quantity selection and instant cart additions.
- Quick-view specification modal with technical compliance sheets.

### 7. Interactive Cart Drawer & Calculation Engine
- Slide-out project cart drawer.
- Line item quantity adjustments and item deletion.
- Live ex-VAT subtotal and UK standard VAT (20%) calculation.

### 8. Construction Site Checkout Flow
- Site delivery address form (street, city, UK postcode, driver telephone).
- Vehicle offload options: Standard Hiab Crane Offload vs. Express Timed Next-Day Slot.
- Commercial payment options: 30-Day Trade Credit Account vs. BACS Corporate Bank Wire.
- Automated invoice and order reference generation (e.g., `FCC-2026-XXXX`).

### 9. Trade & Contractor Quoting Engine
- Multi-category quotation request form for volume contractors.
- Site schedule notes and bill of quantities input.
- Instant quote reference generation with SLA response commitment.

## 📦 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/adekunledeborah750-design/joshua-b.git

# Enter directory
cd joshua-b

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
